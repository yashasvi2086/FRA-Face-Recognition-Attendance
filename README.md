# Face Recognition Attendance System

## 🚀 Overview
A smart attendance system using face recognition with OpenCV and deep learning.

## 🧠 Features
- Real-time face detection
- Face encoding using CNN
- Automatic attendance marking
- Flask backend + React frontend

## 🛠 Tech Stack
- Python (OpenCV, face_recognition)
- Flask
- ReactJS
- Firebase / Database

## 📂 Project Structure
/backend
/frontend
/models

## ▶️ How to Run
1. Clone repo
2. Install dependencies
3. Run backend
4. Start frontend
